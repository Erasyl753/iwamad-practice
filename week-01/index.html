Мен туралы

Сәлем! Мен KBTU-дың 3 курс студентімін. Қазір веб-технологиялар курсын өтіп жатырмын және осы аптада Git-ке алғашқы коммитімді жасадым — бұл бет соның нәтижесі.

Семестр соңына дейін толыққанды портфолио жинап, HTML, CSS және JavaScript тілдерін сенімді меңгергім келеді, содан кейін React-ті де үйреніп көрмекпін.

Дағдылар

  • HTML5 және семантикалық белгілеу
  • CSS: flexbox және торлар
  • Git пен GitHub (негізгі workflow)
  • JavaScript негіздері
  • Командалық жолмен жұмыс

Семестрге мақсаттар

Дағды Қазіргі деңгей Семестр соңына мақсат
HTML/CSS Негізгі Сенімді
JavaScript Жаңадан бастаушы Негізгі деңгей
Git/GitHub Алғашқы коммит Тармақтар мен PR-мен сенімді жұмыс
React Әлі бастамадым Алғашқы шағын жобаны құрастыру

Екінші сурет (бонус): прогрестің шартты графигі — нақты жоба пайда болған соң оны шынайы скриншотпен алмастыруды жоспарлап отырмын.
